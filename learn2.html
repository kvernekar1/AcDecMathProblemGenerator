How to Approach Sequence Problems

Finding the nth Term or n from Two Known Terms

Arithmetic Sequences

When you have two terms in an arithmetic sequence:

  1. Enter the term positions in L1 (e.g., 13 and 25)
  2. Enter the term values in L2 (e.g., 27 and 63)
  3. Press [STAT] → CALC → LinReg(ax+b)
  4. The a value is your common difference, b is your first term
  5. Find any nth term: b + (n-1) × a

Example: If term 13 = 27 and term 25 = 63:

a = 3 (common difference), b = -12 (first term)

Term 50 = -12 + (50-1) × 3 = 135

If you simply want to find what term the number x is(i.e what term number 51 would be):

  1. Find a and b using the same steps mentioned above
  2. Use the formula: n = ((x - b)/a) + 1

Example: If term 13 = 27 and term 25 = 63:

a = 3 (common difference), b = -12 (first term)

The position of the number 51 = ((x - b)/a) + 1 = ((51 - (-12))/3) + 1 = 22nd term

Geometric Sequences

When you have two terms in a geometric sequence:

  1. Enter the term positions in L1 (e.g., 4 and 6)
  2. Enter the term values in L2 (e.g., 27 and 243)
  3. Press [STAT] → CALC → ExpReg
  4. The a value is your first term, b is your common ratio
  5. Find any nth term: a × b(n-1)

Example: If term 4 = 27 and term 6 = 243:

a = 0.333 (first term), b = 3 (common ratio)

Term 9 = 0.333 × 3(9-1) = 2187

If you simply want to find what term the number x is(i.e what term number 9 would be):

  1. Find a and b using the same steps mentioned above
  2. Use the formula: n = (log(x/a)/log(b)) + 1

Example: If term 4 = 27 and term 6 = 243:

a = 0.333 (first term), b = 3 (common ratio)

The position of the number 729 = (log(729/0.333)/log(3)) + 1 = 8th term

Finding the nth Term from One Term and Common Difference/Ratio

Arithmetic Sequences

When you know term x is y and common difference d:

Term n = (n - x) × d + y

Example: If term 21 = 72 and d = 3:

Term 37 = (37 - 21) × 3 + 72 = 120

Term 15 = (15 - 21) × 3 + 72 = 54

If you simply want to find what term the number x is(i.e what term number 15 would be):

  1. Use the formula: n = ((x - y)/d) + x

Example: If term 21 = 72 and d = 3:

The position of the number 54 = ((x - y)/d) + x = ((54 - 72)/3) + 21 = 15th term

Geometric Sequences

When you know term x is y and common ratio r:

Term n = r(n - x) × y

Example: If term 7 = 63 and r = 3:

Term 12 = 3(12 - 7) × 63 = 15,309

Term 5 = 3(5 - 7) × 63 = 7

If you simply want to find what term the number z is(i.e what term number 567 would be):

  1. Use the formula: n = (log(z/y)/log(r)) + x

Example: If term 7 = 63 and r = 3:

The position of the number 567 = (log(567/63)/log(3)) + 7 = 9th term

Finding the Sum of a Sequence

Finite Arithmetic Sequence

When first term is a, common difference is d, number of terms is n:

Sum = [n(2a + (n-1)d)]/2

Example:

Sum of first 10 terms of an arithmetic sequence with first term 2 and common difference 3:

Sum = [10(2 × 2 + (10-1) × 3)]/2 = 155

Finite Geometric Sequence

When first term is a, common ratio is r, number of terms is n:

Sum = a(1 - rn)/(1-r)

Example: Sum of first 5 terms of a geometric sequence with first term 2 and common ratio 3:

Sum = 2(1 - 35)/(1-3) = 242

Infinite Geometric Sequence

When first term is a, common ratio is r (where |r| < 1):

Sum = a/(1-r)

Example: Sum of an infinite geometric sequence with first term 2 and common ratio 0.5:

Sum = 2/(1-0.5) = 4

How to Approach Statistics Problems

Quick Calculation of Statistical Measures

  1. Go to [STAT] → [EDIT]
  2. Enter your data in L1
  3. Go to [STAT] → CALC → 1-Var Stats
  4. Press [ENTER] three times

You will see:

  • Mean (x̄)
  • Median (Med)
  • Quartiles (Q1, Q3)
  • Min and Max values (range = max - min)
  • Standard deviation (Sx)

To get variance, you just square Sx.

Quick Calculation of Expected Value/Variance/Standard Deviation

  1. Go to [STAT] → [EDIT]
  2. Enter the values in L1 and the probability in L2
  3. Go to [STAT] → CALC → 1-Var Stats
  4. Put your cursor next to FreqList and press [2ND] → [STAT] and select L2
  5. Press [ENTER] two times

You will see:

  • Expected Value (x̄)
  • Standard deviation (σx)

To get variance, you just square σx.
